An Echo Show, reborn.

Muse Echo turns an Echo Show 5 into a Muse Gadget: a little device on your nightstand that Muse can draw on, talk through and fill with notes, timers and photos. And it comes with a resident: Puff, a blob who lives on the screen.

You talk. Muse answers.
The Echo does the rest.

Say "hey Muse" or tap the mic. Muse's reply streams in as a caption and is spoken aloud. And because the Echo is a real gadget, Muse can reach back and use it.

Everything Muse can reach.

A Kotlin port of Meta's Linux gadget SDK, plus the push-to-talk chat flow from their ESP32 screen boards. These are the commands Muse can call.

Built for the nightstand.

🌙 Quiet hours

From 22:00 to 07:00: no wake word, no talking, a dim screen and soft beeps. Alarms still ring. After a few idle minutes the screen turns off completely.

📡 Works offline

When Muse can't be reached, voice notes are transcribed on the device and timers, alarms, the time and the last weather are handled locally.

☀️ Morning brief

The first "hey Muse" after quiet hours gets weather, your day and server status, without asking.

🔄 Updates itself

The Echo checks the homelab for new builds every six hours and offers to install them.

Set it up.

You'll need an Echo Show 5 running LineageOS and a Muse account with an SDK token.

1. Install and pair

tools/deploy.sh <adb serial or ip:port>
# optional: let Muse bring the app forward
adb shell appops set com.rusty.museecho \
    SYSTEM_ALERT_WINDOW allow
# setup panel → paste token → Start pairing

2. No Bluetooth LE advertising?

# pair from any Linux box with Meta's own SDK,
# then hand the result to the Echo
tools/pair-via-linux.sh mgst_…
# Bluetooth is only for this one-time setup
The homelab side lives in latitude-services: echo-hub serves status, photos, backups, updates and the phone API, and muse-gadget lets Muse run commands on the server and forwards homelab alerts so the Echo can announce them.
